## נוהל המשך

1. להתחיל ב־`editorial_review`, להשלים כמויות והוראות חסרות בלי להמציא מידע, ולבדוק כל נוסח מול שורת המקור.
2. להשוות את `possible_duplicate` למתכון המסומן ולהימנע מפתיחת מתכון חדש לאותה גרסה. אפשר להוסיף קרדיט למקור או הערה לגרסה קיימת לאחר אישור.
3. `needs_full_recipe`, `ideas_collection` ו־`inspiration_only`: לא לייבא בתור מתכון מלא בלי השלמות; אפשר לשמור כאוסף רעיונות נפרד.
4. לייצר תמונה מקורית ייעודית ואמינה לכל מתכון מאושר; להעלות את המדיה לענף `recipe-media` ולתקן מפת מדיה, לפי `docs/ADDING_RECIPES.md`.
5. לאחר אישור אישי ובדיקות אוטומטיות בלבד, להציע Pull Request לפרסום ולא למזג אוטומטית.
